# C09: debug commands

Features: C09, W09

Minecraft-style commands to change the time and the weather on the
spot, so W09's other hours and weathers can be checked without
restarting with `--hour` and `--weather` (the user found that too
annoying for W09's live check and left those steps for these commands).

## Decided

The user's (2026-10-08): the style (`/weather <kind>`, `/time set
<day, night, {seconds}s, {minutes}m>`), times counted from midnight on
the 28-minute day, and that names and words were mine. They asked me
to build it overnight, right after W10, and to take the open decisions
myself and list them. So these are **mine, for the user to confirm**:

- **Where you type:** a console of its own, opened with `/` while you
  can move (like Minecraft's chat key), not the chat box, whose text
  goes to the session (rejected: a leading `/` in the chat box, which
  would clash with the session's own commands; a separate console key
  like the backquote, harder to find on some keyboards).
- **Commands:** `/time set|add|query|speed`, `/weather
  <kind>|auto|query`, `/lightning` (for the bolt and flash, which are
  rare otherwise) and `/help`.
- **Builds:** debug builds only (`OS.is_debug_build()`), so release
  exports don't have it.
- **Dev flags kept** for now: the live checklists use them, and they set
  the state before the first frame.
- `/weather` jumps at once and holds the kind until `/weather auto`
  (for debugging, waiting a minute for the ease is no use).
- `day` is the launch's mid-morning (10m 22s); `night` is 24m 30s,
  halfway from sunset to midnight.

## What was built

- `DebugCommands` parses and runs a line against `DayNight` and
  `Weather`; `DebugConsole` is the line and the reply. A storm's own
  lightning and `/lightning` share `Weather.strike`.
- The world test checks the parsing, every command and the console
  (opened with the action, Esc, Enter).
