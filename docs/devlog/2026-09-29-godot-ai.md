# Switch to godot-ai

Features: tooling

Replaced the `addons/godot_mcp` plugin (see
[Godot MCP plugin](2026-09-28-godot-mcp.md)) with
[hi-godot/godot-ai](https://github.com/hi-godot/godot-ai) v4.2.3 (user's
decision). The user wanted an open-source alternative once the old plugin
turned out to be non-commercial only and unauthenticated.

## Why godot-ai

Compared 16 Godot MCP projects; shortlisted the three that are MIT, active and
support Godot 4.7:
- **godot-ai (chosen):** drives the live editor, both local connections are
  authenticated with rotating capabilities, targets Godot 4.7+. Costs: a Python
  bridge via `uvx`, and telemetry on by default (we opt out).
- **Coding-Solo/godot-mcp (runner-up):** most popular, no network listener at
  all, but runs Godot headless or launches it rather than working with the open
  editor, and hadn't been updated since April 2026.
- **tugcantopaloglu/godot-mcp:** 157 tools, but its live control goes through
  an unauthenticated TCP port and an autoload added to the game.

## Install

- Fresh install from the release's canonical triple, as its docs require: the
  archive's SHA-256 matched the manifest, the manifest's RSA-4096 signature
  verified against the public key from the repo source at the release commit
  (not the copy inside the archive), and all 313 files matched the manifest.
  The staged git blobs also match, so `.gitattributes` LF normalisation
  doesn't break the plugin's exact-tree checks.
- `addons/.godot_ai_update/` (self-update staging and backups) is ignored.
- Client scope `local`, not a tracked `.mcp.json`: the dock-generated entry
  pins versions and machine paths. The old `.mcp.json` and the old plugin's
  settings file were removed.
- Telemetry disabled with the user environment variable
  `GODOT_AI_DISABLE_TELEMETRY=true`, the plugin's highest-priority opt-out.

## After install

- Smoke test: the registered `godot-ai attach` command completed the MCP
  handshake, listed 47 tools, and `editor_state` returned Godot 4.7.2 and
  project "The Beach". Ports 8000 and 9500 listen on 127.0.0.1 only.
- On first launch the plugin added the `_mcp_game_helper` autoload to
  `project.godot`. It's committed: the plugin re-adds it on every editor launch,
  it only talks over Godot's debugger channel, and its export plugin strips it
  from exported builds.
