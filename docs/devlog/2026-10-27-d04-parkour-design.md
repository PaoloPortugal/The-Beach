# D04: parkour, designed (and W13's new moves, D05's plunger gun)

Features: D04, W13, D05, W03, W11, W04, W06, the hub

The last downtime piece designed with the user the same day, after
fishing, bug catching and the collection (dev logs 2026-10-27-d01-,
-d02- and -d03-). Nothing is built. The agreed design is in NOTES → D04
and W13.

## Taken as settled without asking

- The ID D04 and the scope core (world only).
- Courses never depend on agents.
- Leaving mid-run ends that run and nothing else is lost.
- Courses stand over the open sea, so the beacons stay in view.
- A fall drops you in the sea and back to your last checkpoint.

## Offered and chosen (all my recommendations but one)

- **Which kind first: hub courses** (chosen). A course rises beside
  the hub, and a gate on the hub swaps it for another. Rejected for
  now: between-island courses first (they have to fit the bridge
  tree) and both kinds at once. Between-island courses stay planned
  for later.
- **How courses are made: hand-made from pieces** (chosen). Each
  course is a file, which suits mods later. Rejected: generated
  courses (hard to make fun, and an impossible jump can slip through)
  and hand-made sections chained at random.
- **Timing: a timer and best times**, counting finished runs only
  (chosen). Leaving ends the run, so the timer never needs a pause.
  This settles the Downtime constraint that "a parkour timer must
  pause or be optional". Rejected: no timer; a timer you turn on.
- **New moves: mantle and wall run** (the user's pick). I had
  recommended a mantle alone, as small and forgiving; the wall run
  costs more tuning. Both are W13, a movement feature beside W11.
  The ID was my choice, following W11. Their feel (triggers, timing,
  which walls count) is left open in W13 for when it's built.

## Then the plunger gun (D05)

Before D04 merged, the user added another item, a plunger gun, and
reframed the between-island courses: "just objects you can swing on as
an alternative to bridges", with swinging on the hub's courses too. In
the user's words: "you shoot the plunger, the rope lets you pivot on
the point and you swing". Decided:
- **It sticks to swing anchors only** (recommended, chosen). Rejected:
  any surface (it would make bridges, ziplines and course design moot)
  and specially marked surfaces.
- **Pendulum swing** (recommended, and the user's own description).
  Rejected: reeling in like a grapple, and both.
- **Swing routes beside every bridge** (the user's pick, over beside
  some bridges as I recommended, or instead of some bridges).
- **D05, hotbar slot 4** (recommended, chosen), fired with left click.
