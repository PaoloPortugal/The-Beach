# W07 proper: a fixed order, and timing every wait

Features: W07, A05, C05

## The questions

W07's basic version (the Running list in the sessions menu) left open
question 3: how to sort it, whether a minimap is still wanted, and the
"go to whoever has waited longest" key that A05 held back for W07. Gone
through with the user (2026-10-02):

- **The key: dropped.** No key jumps to the longest-waiting agent. But
  how long each agent has waited is still recorded, in case a later
  feature wants it.
- **Where to record it: the sidecar** (my recommendation, taken). The
  game alone would also work, but its clock would start over on every
  reconnect, so a long wait would look new.
- **Order: fixed, no pinning.** Offered: waiting first then most recent,
  most recent only, or fixed with pinning. The list already used a
  fixed order (clusters by spot, sessions by island), so nothing changed
  in the menu.
- **Minimap: not now**, revisit with W06, when there is a layout worth
  mapping.
- The menu's real look stays with the UI design pass.

## What changed

- **Protocol:** `permission` and `question` get an optional `asked_at`
  (a `timestamp`). Optional, so nothing older breaks.
- **Sidecar:** the registry stamps it in `emit`, before the schema check,
  for every provider. A provider's own value is replaced: one clock for
  all of them, so waits compare across sessions. It's part of the
  stored permission or question, so snapshots carry the same time.
- **Godot:** `SessionStore` already keeps the whole object, so the time
  is there with each request in `pending()`. It now also orders the
  requests a snapshot brings that weren't seen before by `asked_at`:
  until now a snapshot couldn't say whether a permission or a question
  came first, so permissions were simply put first (C05).

## Tests

- Sidecar: a permission and a question get a time between "before" and
  "after" the emit, a provider's own (from 2000) is replaced, and a
  second connection's snapshot has the same times. 167 checks pass.
- Godot: a snapshot with a later permission and an earlier question
  lists the question first, with its time; with the fake provider, a
  real permission arrives timed. All headless tests pass.

Nothing in the game shows the time, so there's nothing to check live.
