The user asked to license the project under MIT "if it's fitting". It fits
the goal of a free public release (donations later are fine under MIT) and
is the most common license for open-source tools. Copyright holder, as
the user asked: Paolo Portugal (dev name moofys). For now everything in the
project is MIT, including the user's own future art (user's decision).

MIT with its own `LICENSE`, and `icon.svg` is CC BY 4.0 (a placeholder,
listed in `assets/CREDITS.md`). New dependencies must allow redistribution
in an MIT project (NOTES.md → Conventions, Security rules).

Anthropic, in line with the branding terms (NOTES.md → Watch items).
