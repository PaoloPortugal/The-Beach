A. Set up
1. Install Claude Code with
   npm under nvm (or fnm,
   Volta): `npm i -g
   @anthropic-ai/claude-code`

   is loaded.
2. Make sure no other claude
   is found: none in
   ~/.local/bin, Homebrew,
   /usr/local/bin.

   --version` works.

   Dock (macOS) or the app
   menu (Linux), not from a
   terminal.
5. Hold Tab, +, start a
   session: no "Claude Code
   wasn't found"?
6. The terminal opens with
   the nvm claude (`/status`
   or `which claude` there).
7. Start a second session:
   no extra wait before the
   terminal opens (the shell
   is asked once per run)?

   of ~/.zshrc (or ~/.bashrc),
   restart the game from the
   Dock: after about 10 s,
   "Claude Code wasn't found"
   and nothing hangs?
9. Remove the `sleep 20`.
   Restart: found again?
