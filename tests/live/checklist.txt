Page Down / wheel scrolls this.
Real Claude. Never pick Fable
(no access). Close the game
between parts when it says.

A. What the game found
1. Start the game with no
   session running. Esc →
   Settings → Providers: a
   "Claude Code" row with
   Browse… and a greyed-out
   Reset? With "Show
   sessions started outside
   the game" on (Game tab,
   the default) it already
   shows the claude.exe it
   found, as in 2; with it
   off it says "Not looked
   for yet: it's found when
   a session starts."
2. Start a session (Tab, +)
   and confirm it in its
   terminal. Back in
   Settings → Providers: the
   row shows your claude.exe's
   full path and "version
   …", no "set by hand"?
3. Does the row read well
   (a long path wraps, the
   buttons under it)?

B. Choosing it
4. Browse…: the Windows file
   picker opens in the
   folder of that claude.exe
   and only shows .exe
   files?
5. Pick a program that isn't
   Claude Code:
   C:\Windows\System32\
   whoami.exe. "Checking…",
   then in red "Not changed:
   That program didn't answer
   as Claude Code (claude
   --version)."? The row
   above still shows the old
   one?
6. Browse… and pick your
   claude.exe: the red line
   goes, the row shows its
   path, version and "· set
   by hand", Reset no longer
   greyed?
7. Start another session: it
   opens in the terminal as
   usual? /exit both.
8. Reset to defaults (bottom
   left): the row stays "set
   by hand"?

C. Kept across a restart
9. Close the game and start
   it again. Settings →
   Providers: at once the same path,
   version and "set by hand"
   (no "Not looked for yet")?

D. When it stops working
10. Close the game. Copy
   claude.exe into a new
   folder, e.g.
   C:\Temp\claude-copy\.
   Start the game, Browse…
   and pick the copy: shown,
   "set by hand"?
11. Delete the copy (or its
   folder). Start a session:
   no terminal opens, and the
   menu says "Couldn't start
   a session: The
   Claude Code set in
   Settings doesn't work:
   There's no program at
   that path. Choose it
   again, or reset it."?
12. Settings → Providers:
   the row says the same, in red?
13. Close the game and start
   it again: the row says it
   again, in red, and still
   no other Claude Code is
   used when you start a
   session?
14. Reset: the row shows your
   usual claude.exe again, no
   "set by hand", Reset
   greyed out? A session
   starts as usual. /exit it.
